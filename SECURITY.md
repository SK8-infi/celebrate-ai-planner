# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository, not in a
public issue. Include the steps to reproduce and the impact you expect. You should receive a
reply within three working days, and a fix or mitigation plan within fourteen.

## Supported versions

Only the latest commit on `main` is supported.

## How Celebrate protects users

The measures in place (input validation, Content Security Policy with Trusted Types, rate and
spending limits, secret handling and supply-chain controls) are described in the
[Security section of the README](README.md#security).
